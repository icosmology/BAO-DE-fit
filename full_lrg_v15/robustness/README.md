# Nuisance-bound robustness rerun

All fits use the existing unthinned v1.5 full-catalogue measurements. Neither simulated catalogues nor published distance values supply the measured data.

The earlier damping/evolution bounds were saturated. This run uses positive beta endpoint values in [0.001,3] and damping endpoint values in [0,30] Mpc/h. It checks fit-range and covariance regularization sensitivity, and provides model-conditional linear/quadratic AP results. Numerical convergence does not constitute mock validation.

See robustness_summary.json for all boundary, sensitivity, and inversion diagnostics. Do not interpret second derivatives fixed by the linear-AP model as independently measured curvature.
